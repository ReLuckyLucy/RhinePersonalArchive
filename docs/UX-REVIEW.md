# 操作入口、页面布局与流程评估

日期：2026-10-22。检查基线：`1dd9bf6`。

实施进度：第一批已完成入口、按钮与跳转调整，包括中文全局入口、首页新建/添加材料、更多操作、按原因处理待整理及资料库管理直达。第二批已完成展开阅读、单档案提取摘要、贡献/原件对照、原件/文字切换、参考类型文案与详情次操作。收藏目录取消收藏时保留当前阅读，返回后再更新列表。下面保留评估时的观察；简历阶段与导出流程仍属于后续批次，见 `TODO.md`。

以下为基线版本的产品评估记录，不代表当前所有问题仍然存在。这是一轮本机操作走查，并非新用户可用性测试。走查覆盖波浪首页、参考档案、经历详情、个人贡献、证明材料、待整理、简历入口及编辑器、资料库标识与设置。评估期间未执行导入、提取、确认事实、保存、导出或资料位置变更。

## 产品判断

系统已经覆盖材料、来源、人工核对与简历版本的完整业务链。当前主要障碍是重要操作不够显眼、入口未直达目标，以及页面按内部数据概念组织，使用者需要自行拼接操作步骤。

保留原有波浪阵列、材质、主题与动效。后续改进应让浏览、整理和简历制作各自拥有清晰的主操作，沿用同一套资料、事实与版本实现。

## 建议的页面职责

- 档案首页：浏览波浪阵列、搜索、添加材料、新建档案，提供容易定位的目录入口。
- 档案详情：阅读、核对与编辑当前经历，显示与该类型/状态匹配的下一步。
- 待整理：按问题列出可直接执行的任务；全库提取状态作为辅助区域。
- 简历工作台：明确选材、编辑、预览与导出；保存草稿与导出版本的意义清晰可见。
- 资料库管理：直接管理当前库的位置、导入与备份；说明每项操作作用于哪一个库。

## 建议实施顺序

1. 入口与按钮：明确文字、主次样式、稳定操作区；管理跳转直达目标。优先修复既有入口，不增加新的业务体系。
2. 详情阅读与核对：压缩单档案提取统计，改善正文空间，让证据与贡献能对照阅读；处理参考类型的提示。
3. 跨页任务流程：待整理按原因定位、简历阶段与导出引导、按需补充目录浏览和材料添加流程。

## 建议验收条件

以下为下一轮验证目标，当前没有实测用户完成时间或成功率。

- 不依赖悬停和快捷键，可以从首页直接辨认搜索、新建、添加材料和设置。
- 点击一项待整理原因后，进入对应字段/事实/材料，保留返回任务的位置。
- 查看材料或核对事实时，主要内容不被重复统计或长工具区挤出视野。
- 未保存文字、滚动位置、选中材料与证据版本在相关操作间得到保留。
- 用户在开始编辑简历时就知道如何预览、保存草稿和导出；没有已确认事实时有明确补充入口。
- 关键动作有完成、进行、失败及不可用的说明；不会依赖新增悬停浮窗解释按钮。
- 正文、按钮、表单与明暗/减少动态效果回归通过；波浪、抽取与归位保持既有规则。
