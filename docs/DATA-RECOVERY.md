# 备份、恢复与故障处理

## 备份包含什么

设置 → 资料位置与备份，输入 8–1024 字符自定口令创建备份。内容包含一致性 SQLite 快照、已登记且仍可读取的材料版本、成功导出的简历和校验清单。它不是资料根目录的任意文件同步，未登记文件和应用依赖不在此承诺内。

输出 `.growth` 使用 scrypt 派生密钥、AES-256-GCM 加密与完整性校验。口令不保存到配置或数据库，遗失无法找回。备份须位于库外，另存一份到独立介质；同盘副本不能防止整盘损坏。

缺失、指纹变化或备份过程中变动的原件会导致不完整报告，不能视为成功。处理原因后重试。文件完成后才由临时 `.part` 改名，备份时避免移动原件。

## 恢复到新库

1. 将 `.growth` 文件放进设置中的备份目录，准备口令和一个**尚不存在**的新目标目录。
2. 刷新恢复区域的备份列表、选择文件，输入口令和新目标后验证。应用检查加密包、路径、大小、SQLite 完整性、外键、逻辑清单和材料指纹。
3. 通过后复制到独占创建的新目标，再核对复制指纹。失败不覆盖当前库，不自动合并冲突。
4. 成功后当前会话仍用原库；点击“切换至已验证的恢复库并重启”，稍后刷新。
5. 核对档案、原件、事实状态和简历。原库保留，可在设置中重新选择。

单包恢复最多十万条目、10 GiB 解包内容。拒绝符号链接、越界、重复路径、不支持的条目或版本。恢复需要临时磁盘空间，请预留解包和复制余量。验证是软件一致性检查，不认证材料真实性。

Docker 路径为容器内路径，恢复目标应在持久化卷内，备份另存容器外；见[容器运行](LOCAL-RUN.md#docker-运行)。新电脑先准备应用、OCR 和 Chromium，再恢复备份。

## 简历编辑恢复

当前源码会在输入暂停约半秒后，把简历表单与尚未正式保存的个人信息保留在当前资料库 SQLite 中。状态栏出现“编辑已自动保存在当前资料库”后，刷新或重新打开程序，可从简历列表选择“恢复编辑”。它不是正式草稿，不会自动更新共用个人信息、确认事实或生成简历版本。点击“保存并预览”仍会执行正式校验。

页面切换会立即尝试保留最新输入；尚未成功保留时，关闭或刷新页面会出现浏览器离开提示。突然断电、强制结束浏览器或忽略提示仍可能丢失最近一次保留之后的输入。自动保存失败时先保留页面、排除故障；若另一页面已修改同一恢复记录，可点击“另存恢复副本”，两份输入会分别保留。列表中的“放弃此恢复记录”只删除对应恢复记录，保留正式草稿。

恢复记录属于当前资料库，也包含在新的加密备份中。旧版备份会先按原清单核验，打开恢复库时再升级结构。恢复旧编辑不会绕过草稿和个人信息的版本检查；遇到冲突时请先保留恢复副本，再核对最新正式数据。

档案与事实表单目前尚不提供跨刷新恢复。会话过期或同一资料库服务重启会安全重连一次；切换资料库后旧页面必须刷新，避免将旧编辑写入新库。

## 手工迁移

首选应用内加密备份/恢复。直接复制时先完整停止应用，再复制整个库，包括 `.rhine-archive`、上传目录和登记原件的相对结构。只复制 `library.sqlite` 不等于完整备份；运行中单独复制主数据库可能遗漏 WAL 内容。

新位置使用可写绝对路径，备份仍在库外。旧库先保留，核对后再处置，不要让两个实例同时写同一库。

## 常见故障

| 现象 | 处理 |
| --- | --- |
| 端口占用 | 停止已确认的旧实例或修改 `RHINE_PORT`；应用不会结束陌生程序。 |
| 会话被拒绝 | 使用 `http://127.0.0.1:端口`；同库自动重连一次，仍失败时先保留输入，再检查环境变量与端口映射。切换资料库后需要刷新。 |
| 改配置不生效 | 检查 JSON 全部字段、权限及环境变量覆盖，查看配置所在目录的日志。 |
| 原件缺失 | 恢复原路径和内容后重新导入；不要拿同名新文件替代证明。 |
| 原件变化 | 重新导入形成新版本，再核对受影响事实。 |
| 提取失败 | 原件保留，检查格式、大小、OCR 资源；下载原件或修订已有提取文字。 |
| 修订冲突 | 重新读取最新版本并核对差异后保存。 |
| PDF 失败 | 检查 Chromium、资源权限与空间；源码版重新 `npm run setup`。 |
| Word 分页不同 | 用实际投递软件打开检查，调整选材后保存新版本。 |
| 备份不完整 | 查看缺失/变化报告，修复原件后重试。 |
| 口令错误或损坏 | 核对口令和完整文件，保留原包；无法绕过加密找回口令。 |
| 异常退出 | 重启并查看默认 `runtime/service.log`，先保全库副本，不盲删数据库。 |

报告问题用合成材料，移除身份、联系方式、证件、真实路径、私密文件名和口令。安全报告见 [SECURITY.md](../SECURITY.md)。
